## What this adds

- **Browser wizard**: capture through review in the browser, paired to a local owner-private service (cookie + CSRF on every write).
- **Guided conversation**: the terminal agent fills fields on the page as it talks with you (`fill`), proposes but never accepts; you decide.
- **Backlog**: cards with method and status, re-ranking, read-only Markdown view, and resumable ideas ("Step N of M").
- **Setup pane**: where ideas live. Option 1 keeps them as Glitch-native Markdown (default). Option 2 stores the address and a write-only key for your own workflow system and tests the connection against the documented contract in `docs/workflow-api.md`. Saving ideas through the API is **not switched on yet**; the pane says so.

- **Hardening**: the browser session needs a per-tab secret on every call (a cookie alone authorises nothing); the launcher only talks to a live owner and signs each control call instead of sending its token; attachments and their folders are owner-only.
