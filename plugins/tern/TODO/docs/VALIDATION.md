## SSH review rework

ClaudeBWAI's c312228 review reproduced three SSH boundary gaps that also existed at b0680a4: option-like destinations, inherited permissive host trust and rapid error polling. The source reader now rejects leading-dash user/host destinations before any SSH process, separates options with `--`, forces `StrictHostKeyChecking=yes` and disables `UpdateHostKeys`. Host polling uses 15 seconds for healthy SSH sources, at least 60 seconds after an error and exponential backoff capped at five minutes; success resets it. Local polling remains 1.5 seconds.

Verification boundaries: two added helper contracts failed before the fixes and pass after them, exercising actual helper CLI/subprocess arguments and rejection before spawning. One native Luau contract covers normal timing, first-error backoff/progression and the cap/reset. The connected real-SSH smoke now removes the remote source, observes stale-success removal and proves the failure count does not increase at the old 1.5-second rate. This test touches the same production error/scheduling callback, not a separate retry implementation. The current suite is 5 helper contracts, 3 native view/polling contracts and 11 connected checks.
