## Description

## v0.3

- **Eight steps:** Capture, Priorities, Methods, Discovery, Exploration, Visualize, Assess, Review. The order of Methods and Discovery is one setting. The Shape step is retired.
- **Discovery** asks the problem, who it is for, how it is done today, **whether it already exists** (comparable products, a source link, how we differ, their licences, or "nothing comparable found" with where we looked), the evidence, what would stop it, and at least one real challenge.
- **Exploration** covers the desired result, alternative routes, uncertainty, scope, the next slice and up to five sketched items with "done when".
- **Launch:** the tab opens already paired; the typed code stays as a fallback. A resume closes the old tab where it can, and a replaced tab says so, with a link for a lost tab.
- **Terminal-first fields:** locked until the agent fills them, with a one-click path to take a step by hand. The agent pauses after ten idle minutes; an open tab with unsaved edits keeps it awake.
- **Visualize** can open a sealed prototype tab on its own port.
- **Accept** always says why it is disabled. **Review** builds the planning prompt.
- **Look:** own font (Unlicense, licence file included), logo and stylesheet. No third-party fetches.
